# Changelog

All notable changes to Job Application Organizer will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-06

### Added
- Initial release
- LinkedIn Easy Apply automation with intelligent form filling
- Excel tracker with color-coded status system
- Daily reporting system with application statistics
- Auto-archiving of applications after 45 days
- Duplicate detection (won't reapply within 90 days)
- Human-like typing delays and randomized intervals
- Cover letter auto-generation from templates
- Claude Code skill integration (`/job-application-organizer`)
- Configurable daily application limits
- Keyword filtering system
- Organized folder structure with automatic company folder creation
- Batch scripts for Windows (setup, run, schedule)
- Complete documentation and installation guide

### Security
- Daily application limits to avoid platform detection
- Randomized cooldown periods between applications
- No credentials stored in distributed files
- .gitignore for sensitive data protection
